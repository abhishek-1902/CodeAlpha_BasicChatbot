A simple rule-based chatbot developed in Python for the CodeAlpha Python Programming Internship.

## Features
- Accepts user messages through the console.
- Recognizes greetings.
- Responds to "how are you".
- Explains its identity and capabilities.
- Handles thanks.
- Ends the conversation with `bye`, `exit`, or `quit`.
- Provides a fallback response for unknown messages.

## Technologies
- Conditional statements
- Functions
- Loops
- String handling

## Sample Output
```text
===== BASIC PYTHON CHATBOT =====
Type 'bye', 'exit', or 'quit' to end the chat.

You: hello
Bot: Hello! Nice to meet you.

You: how are you
Bot: I'm doing great! Thanks for asking.

You: what can you do
Bot: I can respond to a few predefined messages.

You: bye
Bot: Goodbye! Have a great day.
```
